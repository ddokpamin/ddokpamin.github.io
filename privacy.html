개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-09-26

1. 적용 대상 / Scope

이 방침은 똑파민 채널 운영자가 자신의 채널 관리에 쓰는 내부 도구 "똑파민 스튜디오(ddokpamin studio)"와 이 웹사이트에 적용됩니다.

This policy covers "ddokpamin studio", an internal tool the ddokpamin channel owner uses to manage their own channels, and this website.

2. 이용하는 정보 / Information we access

똑파민 스튜디오는 운영자 본인이 승인한 계정에만 접근합니다.

  • YouTube Data API: 운영자 본인 채널에 영상 업로드(비공개), 채널·영상 정보와 통계 조회
  • Instagram Graph API: 운영자 본인 계정에 릴스 게시, 게시물 정보와 통계 조회

The tool accesses only accounts the owner has authorized: uploading videos (as private) to and reading channel/video data and statistics from the owner's YouTube channel via the YouTube Data API, and publishing Reels to and reading insights from the owner's Instagram account via the Instagram Graph API.

이 웹사이트는 방문자의 개인정보를 수집하지 않으며 쿠키나 분석 도구를 사용하지 않습니다.

This website does not collect visitor data and uses no cookies or analytics.

3. 이용 목적 / How it is used

접근한 정보는 운영자 본인 채널의 콘텐츠 게시와 성과 확인에만 사용합니다. 판매, 광고, 제3자 제공, AI 모델 학습에 사용하지 않습니다.

Data is used only to publish content to and review the performance of the owner's own channels. It is never sold, used for advertising, shared with third parties, or used to train AI models.

똑파민 스튜디오가 Google API로부터 받은 정보의 사용 및 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

ddokpamin studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 보관 / Storage

인증 토큰은 운영자의 기기에만 소유자 전용 파일 권한으로 저장되며 외부 서버로 전송되지 않습니다. 운영 기록은 운영자 기기의 로컬 데이터베이스에 보관합니다.

Authorization tokens are stored only on the owner's device with owner-only file permissions and are never sent to external servers. Operating records are kept in a local database on the owner's device.

5. 접근 철회 / Revoking access

Google 계정 권한은 Google 계정 → 타사 연결에서, Instagram 권한은 Instagram 설정의 앱 및 웹사이트 메뉴에서 언제든 철회할 수 있습니다. 철회하면 해당 토큰은 즉시 사용할 수 없게 됩니다.

Google access can be revoked at any time at Google Account permissions, and Instagram access in Instagram's "Apps and websites" settings. Revoked tokens stop working immediately.

6. 삭제 요청 / Data deletion

아래 주소로 요청하면 도구가 보관한 데이터를 30일 이내에 삭제합니다.

On request to the address below, data held by the tool is deleted within 30 days.

7. 변경 / Changes

방침이 바뀌면 이 페이지의 시행일을 갱신합니다.

Changes are reflected by updating the effective date on this page.
